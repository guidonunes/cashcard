## Key Concepts and Learning Outcomes

This project was developed as part of a Spring Boot course, focusing on REST API development, software architecture, and test-driven development practices.

- **RESTful API Design:** Implemented REST endpoints using HTTP methods such as GET, POST, PUT, and PATCH.
- **HTTP Standards:** Applied appropriate HTTP response status codes, including 200 OK, 201 Created, and 204 No Content.
- **Spring Framework:** Explored Inversion of Control (IoC), dependency injection, annotations, and Spring Boot's auto-configuration capabilities.
- **Layered Architecture:** Structured the application with separation of concerns, leveraging Spring Security for access control, Spring Web for HTTP communication, and Spring Data for persistence.
- **Test-Driven Development (TDD):** Adopted a test-first approach to guide implementation and ensure application reliability.
- **Steel Thread Approach:** Validated architectural decisions early by implementing an end-to-end flow across all application layers, reducing integration risks.
- **Red-Green-Refactor:** Iteratively improved code quality, maintainability, and test coverage throughout the development process.
